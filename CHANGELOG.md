# Template changelog

## 1.7.0

- Poster replacement defaults off; keep existing posters unless explicitly selected.
- Catalog appearance is separate from add-on replacement and defaults off. It includes catalog overrides, merged catalogs where supplied, and category colors.
- Service wrapping is separate from playback and defaults off. Opt in to Redhair’s TorBox-only wrapping.
- Usenet preloading has a separate opt-in switch, off by default. Enabling applies preloading of the first Usenet result without enabling Usenet add-ons.
- Added this history and a short version-change notice in the wizard.

Off preserves existing settings; it does not disable existing features. Other section defaults, quality logic and formatter layouts are unchanged. Existing saved wizard preferences can retain prior choices; review switches before applying.
